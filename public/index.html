🎮 Custom Keyboard Controls

Click any field and press a key to remap it. These bindings are remapped in the browser before being passed to the Flash game — useful for games with hardcoded awkward keys.

These bindings remap keys for Flash games. Console ROMs (NES/SNES/GB/Genesis) use their own controls — while a ROM runs, hover the top edge of the screen to open the emulator menu, then ⚙ to remap keys, wire a gamepad, or manage save states.

⚡ Performance Settings

Applied on next game load. Useful for resource-intensive games. Changes don't affect a currently running game — hit Restart after saving.

WebGPU gives the best performance on supported browsers (Chrome 113+). WGPU-WebGL is the current default and works everywhere. Canvas is best if you see thick/broken strokes.
Lower quality reduces GPU load significantly on intensive games.
Capping FPS reduces CPU/GPU usage for heavy games. Setting it higher than the SWF's native rate has no effect.
Raise this if a complex game freezes mid-load saying a script timed out. Unlimited is risky — a broken game could hang your browser tab.
